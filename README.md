# Shorts

A mobile-first short-video app with an Arabic, right-to-left interface. Browse a vertical feed, record and post clips, and get comments and notifications.

**Live demo:** https://shorts-app-chi.vercel.app

## Stack
- HTML, CSS and JavaScript (front end)
- Tajawal font, responsive layout for phones
- Deployed on Vercel

## Run locally
Serve the folder with any static server and open `index.html`:

```bash
npx serve .
```
